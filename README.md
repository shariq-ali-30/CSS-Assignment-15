# Upwork Landing Page Clone

## About The Project

This project is an Upwork landing page clone created using HTML and CSS.

The purpose of this assignment was to practice building a professional business landing page, creating modern website layouts, improving responsive design skills, and replicating a real-world freelance platform interface inspired by Upwork.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts (Inter)

## Features

- Upwork-inspired responsive landing page
- Professional navigation bar with menu links
- Hero section with call-to-action buttons
- Responsive website layout
- Service categories section with icons and illustrations
- "How It Works" section with images and embedded video
- Pricing and plans section
- Customer reviews/testimonials section
- Footer with useful links and company information
- Modern typography using Google Fonts
- Hover effects and interactive UI elements
- Clean and organized page structure

## What I Learned

Through this assignment, I learned:

- How to recreate a real-world landing page design
- How to build responsive page layouts using HTML and CSS
- How to organize large sections of a website efficiently
- How to use Font Awesome icons and Google Fonts
- How to improve UI design with spacing, colors, and typography
- How to create reusable components for modern websites
- How professional business websites are structured
